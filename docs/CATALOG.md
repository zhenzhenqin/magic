# 美食图鉴

本人手账保存后，在同一事务按名称维护图鉴关联。名称使用 Unicode NFKC、大小写折叠及去空白，有限别名表将「牛角包」「可颂（牛角面包）」等归为「可颂」。原始食物名称及 AI 人工修正标记仍保存在原明细。用户可单独编辑显示名或分类、选择有效用餐照片、收藏或合并。

食用次数按不同餐次 ID 计算。相同食物在同一餐出现两条明细时，记一次用餐和两条明细。首次、最近使用用餐记录的本地日期，最近收集排序依据用餐时间。编辑和删除后即时重算。普通列表只显示现有用餐记录对应的条目，收藏可显示「已无有效记录」。

选定封面优先。其余优先使用带贴纸的有效餐次照片，再按最近用餐和照片顺序取代表图。多项食物共用的照片标为「整餐图」。合并在所有权核对后重写名称映射和明细关联，保留用餐记录原文及历史。搜索、分类、收藏、排序、历史和浏览列表均支持分页。
