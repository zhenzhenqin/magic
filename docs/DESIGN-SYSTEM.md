# FoodDiary 设计规范

## 视觉审查与方向

阶段 7.2 的 API 页面已经用连续纸页和实际贴纸建立了手账体验。其桌面侧栏、登录双栏整卡、独立设置面板和重复的圆角阴影让其他页面更像管理工具。阶段 7.3 采用统一的横向页眉、清晰分组和纸面留白。

| 方向 | 阅读线索 | 取舍 |
| --- | --- | --- |
| A 日常食物标本册 | 暖纸、鼠尾草、偏棕手写注记、纸边和照片贴纸 | 作为默认，给食物照片留下主要彩色空间并保留中文手账气质 |
| B 极简摄影手账 | 黑白墨色、平整照片区、克制的系统字体 | 作为小范围探索，同一实际页面采用临时覆盖样式比较，不维护第二套界面 |

## 统一组件

- 配色以纸白 `#F7F5EE`、暖灰 `#EAE7DC`、墨色 `#30332B` 和鼠尾草 `#89937D` 为主，深绿用于可操作项。食物名称与日期用现有授权的霞鹜文楷子集，正文和表单用系统字体，标题采用现有 Noto Serif SC 子集。两个字体的许可证随源码保留。
- 手账按实际餐次分节，连续纸面仅用细线标注边缘。贴纸沿用实际长宽比及稳定布局。首页压低热量字号，展开后保留未知值及估算来源。
- 手机底部为手账、拍照、图鉴，顶部可进入好友和个人。桌面随横向页眉在同一位置访问。表单保持清晰焦点、16 px 输入或适合手机的默认字号，以及不小于 44 px 的主要交互目标。
- 好友列表和账号中心以细线分组，保留所有共享授权控件。图鉴延用认证缩略图，无需预载高清原图。
- 相机保留取景冻结、真实 Alpha 轮廓、渐隐、白边与入账。动画读取既有 400 px 透明缩略图。原图与贴纸同坐标配准需要 Worker 返回抠图裁切坐标，并补偿白边留白及方向比例。本轮未新增坐标协议或重新推理。
- 支持系统减少动态效果及相册降级。真实移动键盘、iPhone Safari 和 Android Chrome 待真机验收。
